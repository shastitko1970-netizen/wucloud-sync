Как загрузить бэкап на Nest
  1. На телефоне или компьютере должен быть файл бэкапа SillyTavern — обычно .zip (скачали раньше из Nest или из своей локальной ST).
  2. Нажмите зелёную кнопку «Загрузить бэкап с компьютера» и выберите этот файл.
  3. Смотрите статус ниже: пока идёт загрузка — «занято», когда готово — страница обновится сама. После этого откройте список чатов.
  4. Если интернет оборвался на середине — не паникуйте: выберите тот же файл ещё раз. Уже залитые части (до ~48 часов) на сервере останутся, докачается только недостающее. Не начинайте с другого файла.

Подходят: .zip, .tar.gz. Не подходит: папка без архива, скриншот, одиночный .json чата. На телефоне лучше не гасить экран и не сворачивать браузер до конца загрузки.

Обычные действия
Кабинет Nest

Автосохранение на диск: примерно каждые 2 минуты, пока вкладка открыта. Кабинет — профиль и квота, не загрузка бэкапа. Ключи и золото: WuApi Dashboard.

Опасная зона

Стереть весь дом Nest удаляет чаты, персонажей, настройки, worlds, расширения. Аккаунт входа останется. Сначала лучше «Скачать бэкап (.zip)».

Портал / квота Gold и ключи wu-gold

External bridge · packs — один zip-снимок data ST ↔ облако WuProj (переезд на другой ПК / в Nest). Не dual-model по компонентам. Ключ: wu-… из Dashboard → API keys.

Логи: блок «Журнал» · F12 → [WuCloud]. Dashboard → WuCloud packs.

Действия (packs)

Push = ST /api/users/backup (zip) → /api/v2/wucloud/packs. Если multi-user backup недоступен — JSON pack (fallback). Pull скачивает zip в браузер → Data Management → Import в ST.
